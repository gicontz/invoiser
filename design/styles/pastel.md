# Pastel — "Soft Ledger"

**Who it's for:** creative freelancers — illustrators, designers, coaches, photographers —
who want an invoice that still feels like *them*, not a form spat out by accounting software.

## Palette

| Token | Hex | Use |
|---|---|---|
| Sage | `#8FA893` | Primary accent — rules, section labels, badges |
| Clay blush | `#E3AF9C` | Secondary accent — totals highlight, tags |
| Periwinkle | `#A8AEDC` | Tertiary — status pills, sparing use only |
| Linen | `#FAF6F0` | Page background |
| Cloud | `#F1EAE3` | Card fill |
| Ink plum | `#3D3644` | Body text (soft dark plum, not pure black) |

Muted, dusty tones — not candy pastels. Nothing here is a gradient; each color is a flat fill.

## Type

- **Headings:** Quicksand (rounded terminals, friendly without being childish)
- **Body / data:** Karla (clean, humanist, keeps line-item numbers legible)

## Layout

- Rounded cards, 18px radius, very soft shadow (`0 2px 8px rgba(61,54,68,0.06)`)
- Generous padding, left-aligned content throughout
- One soft rounded accent shape in the header corner — a signature, not a watermark
- Grand total sits in a filled sage pill, not a boxed table row
- Line-item rows separated by whitespace, not hairlines — the softness carries the rhythm
- When a cap is applied and exceeded, add a quiet "Logged total (uncapped)" line above the pill
  in clay blush, and the pill itself reads "Total due (capped)" — the softness should make the
  cap feel like a kindness, not a penalty

## Principle

*Warm and handmade.* It should read like a note from someone who cares about the work,
while the numbers themselves stay perfectly legible — softness is a mood, not a compromise
on data clarity.
