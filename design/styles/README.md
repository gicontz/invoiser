# Invoiser design styles

Candidate visual designs for the invoice **output** (print / PDF / email) — the marketplace
feature will let a user pick one of these to skin their exported invoice. The live editor form
itself stays plain and unstyled by these designs; only the generated document changes.

- [`pastel.md`](pastel.md) — soft, warm, handmade — for creative freelancers
- [`elegant.md`](elegant.md) — restrained ledger/letterhead — for consultants and agencies
- [`flat.md`](flat.md) — bold color-block product aesthetic — for studios and startups

Status: **concept stage, pending approval.** No CSS implementing these has been built yet —
see each file for palette, type, and layout direction. Once approved, each becomes a
themed stylesheet applied at export time only.

A side-by-side visual moodboard (swatches, type specimens, mock invoice previews) was
published for review — ask for the link if you don't have it handy.
